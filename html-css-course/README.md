# HTML & CSS course projects

Các bài thực hành được nhóm theo chủ đề. Mỗi trang HTML dùng stylesheet bên ngoài; các thư mục portfolio có stylesheet riêng.

## Flexbox và CSS Grid

- `my-first-website/centered-card.html` — căn giữa nội dung bằng Flexbox.
- `my-first-website/product-grid.html` — lưới thẻ sản phẩm co giãn.
- `my-first-website/blog-layout.html` — bố cục blog hai cột với CSS Grid.
- `my-first-website/creative-layout.html` — mosaic bất đối xứng với `grid-column` và `grid-row`.
- `my-first-website/newspaper.html` — trang báo chuyển từ nhiều cột sang một cột ở màn hình nhỏ.
- `my-first-website/responsive-nav.html` — menu hamburger CSS.

## Portfolio responsive

- `my-first-website/portfolio-responsive/homepage.html` — một cột trên mobile, hai cột trên tablet và mosaic bốn cột trên desktop; có ảnh art direction cho màn hình nhỏ.
- `my-first-website/portfolio-final/index.html` — trang chủ portfolio.
- `my-first-website/portfolio-final/about.html` — giới thiệu và kỹ năng.
- `my-first-website/portfolio-final/projects.html` — ba dự án có ảnh và mô tả.
- `my-first-website/portfolio-final/contact.html` — biểu mẫu liên hệ và liên kết mạng xã hội mẫu.

Portfolio cuối khóa dùng nội dung mẫu “Minh Anh” và `hello@example.com`. Hãy thay bằng thông tin của bạn trước khi dùng làm hồ sơ cá nhân; biểu mẫu hiện chưa kết nối dịch vụ gửi tin nhắn.
