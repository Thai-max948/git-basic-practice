# Portfolio cá nhân

Portfolio nhiều trang dùng HTML5 ngữ nghĩa, external CSS, Flexbox, CSS Grid, mobile-first media queries, đơn vị tương đối và responsive image art direction.

Trước khi dùng làm hồ sơ cá nhân, thay tên “Minh Anh”, email `hello@example.com` và các liên kết hồ sơ mẫu trong các trang HTML bằng thông tin của bạn. Biểu mẫu liên hệ hiện chỉ có giao diện, chưa kết nối dịch vụ gửi tin nhắn.
