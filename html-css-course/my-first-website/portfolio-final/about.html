MỘT CHÚT VỀ MÌNH

Học bằng cách làm, tiến bộ qua từng phiên bản.

Mình là Minh Anh, một người học phát triển web. Mình quan tâm đến cách nội dung, bố cục và tương tác kết hợp để tạo nên một trải nghiệm dễ dùng.

Về mình

Mình đang xây dựng nền tảng HTML5 và CSS3 thông qua các bài thực hành nhỏ. Khi bắt đầu một giao diện, mình thường nghĩ về người sẽ sử dụng, nội dung họ cần tìm và cách trình bày sao cho dễ theo dõi.

Mình yêu thích việc thử nghiệm các bố cục mới, kiểm tra giao diện trên nhiều kích thước màn hình và chỉnh sửa chi tiết dựa trên kết quả thực tế.

Học tập

Hiện mình đang tập trung vào cấu trúc HTML ngữ nghĩa, CSS Box Model, Flexbox, CSS Grid, media queries và khả năng tiếp cận cơ bản. Các dự án trong portfolio là những bài thực hành mình đã xây dựng trong quá trình học.

Kỹ năng đang rèn luyện

  • HTML5 ngữ nghĩa
  • CSS3 và mô hình hộp
  • Flexbox và CSS Grid
  • Thiết kế mobile-first
  • Responsive images
  • Kiểm tra cấu trúc và khả năng truy cập
