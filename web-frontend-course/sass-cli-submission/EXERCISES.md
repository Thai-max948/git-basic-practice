# Sass exercise files

The CLI project is available directly in this repository folder. The additional exercise projects are packaged with their original directory structure in `examples.zip`.

- `examples/css-to-scss/` — CSS refactor with variables, mixins, nesting, and the requested `abstracts`, `base`, `layout`, and `components` folders. Activities 1556 and 1557.
- `examples/responsive-grid-sass/` — Sass refactor of the CodeGym responsive-grid starter. Activity 1515.
- `examples/portfolio-sass-refactor/` — refactored multi-page portfolio with compiled styles and local images. Activity 1516.

To build after extracting `examples.zip` into this folder, run `npm install` and `npm run sass:all`.
